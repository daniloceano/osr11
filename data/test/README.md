# `data/test/` — Test NetCDF Datasets

Small domain cutouts of the operational CMEMS reanalysis datasets, committed to the repository for development, testing, and pipeline validation. Full-resolution raw downloads are not committed (see `data/raw/` and `.gitignore`).

Two spatial domains are covered: the southern SC coast and the full SC coast.

## Spatial domains

### Southern SC domain (`*_sc_sul_*`)

```
Latitude:  −29.4°S to −27.6°S
Longitude: −50.0°W to −48.0°W
```

Covers the southern portion of the Santa Catarina coast, roughly from the Florianópolis–Palhoça area southward toward the border with Rio Grande do Sul.

> **Important**: Municipalities in the northern and central-north sectors of SC (e.g. Itapoá, São Francisco do Sul, Balneário Camboriú, Navegantes) are outside this test domain. Grid-based statistics are therefore unavailable for those municipalities when using the southern-domain files.

### Full SC domain (`*_sc_full_*`)

Covers the complete Santa Catarina coastline extent (north to south). Used by Steps 2b onwards in the threshold calibration pipeline.

## Generation

To regenerate these test fixtures from a local full-resolution download:

```bash
python src/01_data_preparation/acquisition/build_test_fixture.py
```

Configure the input paths in `config/test_fixture.example.yml` (copy to `config/test_fixture.yml` before running).

---

## Known limitations

- Test cutouts only — they do not replace the full operational datasets used for production runs.
- The southern-domain files (`*_sc_sul_*`) cover only the southern portion of the SC coastline.
- The unified file (`metocean_sc_full_unified_waverys_grid.nc`) depends on the regridding preprocessing step; verify it is current if the source files are updated.
- Results produced from these files during development should not be interpreted as final.
