# `issues/archive/` — Questões arquivadas

Diretório para registros de questões que foram **fundidas em outra questão** ou
**tornadas obsoletas** por uma mudança de escopo.

## Regras

1. Um registro arquivado **mantém seu identificador original**. `AUD-NN` nunca é
   reaproveitado — o identificador pode estar citado em commits, mensagens ou no
   manuscrito.
2. Antes de mover, preencha no cabeçalho do registro:
   - `Status`: `arquivado`
   - `Desfecho`: `substituido-ou-fundido` (ou o desfecho aplicável)
   - `Relacionado a`: o `AUD-NN` que absorveu a questão
3. Acrescente uma entrada final no **Histórico de investigação** (§14) do
   registro explicando por que foi arquivado e para onde foi o conteúdo.
4. Mova a linha correspondente do [`ISSUE_TRACKER.md`](../../ISSUE_TRACKER.md) da
   tabela mestra (§2) para a tabela de arquivadas (§9). **Nunca apague a linha.**

## Arquivar não é resolver

Uma questão arquivada **não** está resolvida. Se o problema científico continua
existindo, ele deve estar rastreado na questão que a absorveu. Arquivar por
conveniência, sem que outra questão assuma o problema, equivale a apagar um
achado da auditoria.
